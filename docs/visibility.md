# 三档可见性：门户 / 持链接 / 仅自己

结论先说：**「门户」和「持链接」在权限上完全一样，差别只在「是否被列进访客门户」；
「仅自己」不是「登录就能看」，而是「只有作者本人或管理员登录后才能看」。**

## 一、判定表

| | 门户可见 `portal` | 持链接可见 `link` | 仅自己可见 `private` |
|---|---|---|---|
| 出现在门户首页（`/`） | ✅ 是 | ❌ 否 | ❌ 否 |
| 知道 `/v/<slug>` 就能打开 | ✅ 任何人 | ✅ 任何人 | ❌ 只有本人 / 管理员 |
| 匿名（未登录）访问 `/v/<slug>` | 200 | 200 | **302 回门户** |
| 其他已登录成员访问 | 200 | 200 | **302 回门户** |
| 作者本人登录后访问 | 200 | 200 | 200 |
| 管理员登录后访问 | 200 | 200 | 200 |
| 搜索引擎 | `noindex` | `noindex` | `noindex` |
| 新建时的默认寿命 | 6 小时 | 12 小时 | 永久 |

`portal` 和 `link` 这两行的「200」是**不带任何身份校验**的：URL 就是唯一凭据，
转发给谁，谁就能看。所以「门户」不等于「安全」，「持链接」也不等于「私有」。

## 二、三个常见误解

**误解 1：「门户包含链接」**
从**曝光**角度成立（进了门户的项目一定也在链接层可见）；从**权限**角度不成立——
两者对项目页的判定完全一致，`portal` 只是额外多了一次「出现在列表里」。
因此把项目从 `link` 改成 `portal`，改变的只是它会不会被人逛到，不会改变谁能打开它。

**误解 2：「链接只能走正确路径访问」**
没有「正确路径」这回事，`/v/<slug>` 就是全部。slug 是随机/语义化短串，
猜中的概率低，但一旦漏出去就等于公开。真正的访问控制只有 `private` 才有。

**误解 3：「私有是登录后就能访问」**
不是。判定条件写死在 `backend/app/routers/public.py::_public_state`：

```python
if row["visibility"] == "private":
    allowed = bool(user) and (user["role"] == "admin" or row["owner_id"] == user["id"])
    if not allowed:
        return False, expired     # 不可见，交给上层统一 302 回门户
```

也就是说：**登录了但不是作者、也不是管理员 → 依然打不开**。
打不开的表现不是 403，也不是「一个写着 404 的页面」，而是 **302 回门户首页**：
既不说「你没权限」也不说「项目不存在」，外人从 URL 和状态码上都判断不出这个 slug 有没有东西。
门户本身要登录时，会继续 302 到 `/admin/login`，连门户内容都不会漏。

## 三、私有链接到底怎么打开

私有项目**没有**能发给外部人的链接。它的打开方式只有三种：

1. **在控制台点「打开」**：项目页/门户里点开，走的是你当前浏览器的登录态。
2. **同一个浏览器里贴 URL**：`https://<站点>/v/<slug>`。登录态存在 Cookie 里，
   同一个浏览器新开标签页照样能进；换浏览器、换设备、无痕窗口就回门户首页。
3. **管理员代看**：管理员在任何设备登录后打开同一个 URL 也能进（用于审核）。

要让**别人**看到，正确做法是把可见性改成 `link`（持链接可见）：
这样对方拿到 URL 就能打开，且项目不会出现在门户列表里。临时验收就选它。

> 权限是「按账号」不是「按链接」的，所以私有项目没法靠加参数、加 token 绕过。
> 需要「给不同人不同链接」这类需求，目前不支持，只能用 `link` + 到期时间控制窗口期。

## 四、和「到期」的叠加关系

可见性决定「谁**有资格**看」，到期时间决定「**现在还**能不能看」，两者是 AND 关系：

- 过期后三档统一 **302 回门户首页**，`private` 对作者也一样（作者本人看到的是「链接已失效」提示条）；
- 门户列表只收 `status='active'` 且未到期的项目，所以过期的项目即使设成 `portal` 也不会出现；
- 批量把已过期项目设为门户可见时，接口会返回 `expired` 计数，前端提示「需先续期」。

## 五、怎么选

| 场景 | 选哪档 |
|---|---|
| 给客户临时验收，不想被其他人逛到 | `link` + 到期时间 |
| 团队内部共享、希望有个统一入口 | `portal` |
| 半成品 / 内部数据 / 只给自己回看 | `private` |
| 已经发出去的链接要立刻作废 | 改 `private`（外部立刻打不开、跳回门户）或直接删除 |

## 六、接口层怎么改

```bash
# 单个
PATCH /api/projects/{slug}   {"visibility": "portal"}
# 批量
POST  /api/projects/bulk     {"slugs": ["a","b"], "action": "visibility", "visibility": "portal"}
```

`visibility` 只接受 `portal` / `link` / `private`，其它值返回 **400**。
`publisher` 只能改自己的项目，改别人的会在批量里被计入 `skipped`。
